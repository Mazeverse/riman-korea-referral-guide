# RIMAN Korea Referral Guide

Static landing page for `https://riman.tire210.com/`.

## Deploy
Upload the four files in this folder to the root of the GitHub repository `riman-korea-referral-guide`, then import it in Vercel as a static project.

In Vercel Settings > Domains, add `riman.tire210.com` and follow the **exact CNAME target** displayed by Vercel in Hosting.kr DNS. Do not modify existing DNS records.

The page includes the Google Search Console verification meta tag. Add a new Naver verification meta tag once issued for this domain.

This is an independent referral information page, not an official RIMAN website. Verify referral program and signup details against the official site before publishing.
